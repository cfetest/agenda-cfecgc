Agenda unifié CFE-CGC Orange FC : le mail est lu sur ce PC uniquement, rien n'est envoyé.

1Rendez-vous mail actuels

    2Ajouter ou modifier un rendez-vous

    Dépose ici le fichier .eml (ou clique pour le choisir)
    Dans Outlook : glisser le mail sur le bureau crée le fichier .eml (ou .msg : dans ce cas, remplis le formulaire à la main).

    L'adresse ou « Teams » dans le résumé sert à placer le rendez-vous sur la carte et à détecter présentiel / distanciel. Plusieurs jours : écrire « du 7 au 10 décembre ». Aucun lien, aucun numéro de téléphone, aucun nom de destinataire.

    Texte du mail (pour relire et copier des passages) :
    Aucun mail chargé.

    3Publier sur GitHub

    2. Ouvrir ajouts.json sur GitHub (modification) et se connecter avec le compte cfetest si demandé.
    3. Dans l'éditeur : Ctrl+A puis Ctrl+V.
    4. Bouton vert Commit changes... puis Commit changes. Le site se met à jour en 3 à 5 minutes.

    Autre possibilité : puis sur GitHub Add file → Upload files → déposer le fichier → Commit changes.
