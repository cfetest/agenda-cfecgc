1Ajouter ou modifier un rendez-vous

Dépose ici le mail .msg (Outlook) ou .eml (ou clique pour le choisir)
Outlook (.msg) : glisser le mail d'Outlook vers le bureau, puis déposer le fichier ici. Les fichiers .eml sont aussi acceptés.

L'adresse ou « Teams » dans le résumé sert à placer le rendez-vous sur la carte et à détecter présentiel / distanciel. Plusieurs jours : écrire « du 7 au 10 décembre ». Aucun lien, aucun numéro de téléphone, aucun nom de destinataire.

Texte du mail (pour relire et copier des passages) :
Aucun mail chargé.

2Publier sur GitHub

  2. Ouvrir ajouts.json sur GitHub (modification) et se connecter avec le compte cfetest si demandé.
  3. Dans l'éditeur : Ctrl+A puis Ctrl+V.Tout sélectionner, puis remplacer en collant.
  4. Commit changes (deux fois). Le site se met à jour en 3 à 5 minutes.En ligne sous 5 min.

Autre possibilité : puis sur GitHub Add file → Upload files → déposer le fichier → Commit changes.

    Les champs du fichier ajouts.json
    
  
    
    
    t
    Titre, en gras sur la carte.
    Webinaire : Transformations et réorganisations
    
    
    d
    Date, au format AAAA-MM-JJ : jour dans Prochains et Agenda.
    2026-11-17
    
    
    h
    Horaire : heure sur la carte et bloc dans la frise. Vide = « Horaire non précisé ».
    09h30 - 11h00, 18h00 ou vide
    
    
    g
    Étiquette : lieu ou type, court. Pas affichée sur les cartes mail : sert à la recherche, au lieu sur la carte et au mode.
    Orange Bridge, Webinaire URIF
    
    
    x
    Résumé, visible quand la carte est dépliée.
    Organisé par l'URIF. 63 rue du Rocher, 75008 Paris.
    
    
    u
    Lien : toujours vide pour les mails (aucun lien publié). La carte affiche « Liste de diffusion → ».
